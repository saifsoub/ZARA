# ZARA — plain-language README

## What this is
A one-page control panel for keeping track of your personal AI experiments: which AI helpers you have, your saved prompts (instructions you give an AI), what you ran and where things are hosted.

## Who it's for
Someone tinkering with AI tools who wants a simple notebook-style dashboard, with no account and no server.

## What it does today
- **Agents:** list and track your AI helpers.
- **Prompts:** save prompt templates and copy them with one click.
- **Runs:** note what you ran and how it went.
- **Deploy:** list the web addresses your tools use.
- **Modes:** switch between Build, Research and Deploy views.
- **Import / Export:** save everything to a file or load it back.
- **Reset:** clear everything.

All data stays in your own browser. Nothing is sent anywhere.

## How to run it
Open `index.html` in a modern web browser. That's it.

## Current status and known gaps
- Works offline in your browser.
- There is a setting for a web address to send data to, but that sending isn't built yet.
- Clearing your browser data also clears ZARA. Use Export to keep a backup.
